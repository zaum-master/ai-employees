# Start an AI employee

If you are using a remote GitHub link in Codex, Claude, or another coding
agent, paste this message alongside the link:

```text
Retrieve or clone https://github.com/zaum-master/ai-employees, read AGENTS.md,
and begin the onboarding flow now. Your first response must ask: “Which AI
employee would you like me to create?” Do not review or summarize the
repository first.
```

A repository cannot control an agent that cannot retrieve its contents. If the
agent says it cannot access the link, clone the repository into its workspace
or use the same prompt with a local repository path.
